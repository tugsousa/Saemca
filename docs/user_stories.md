# User Stories & Epics

## Epic 1: The "Material Gatekeeper" (Risk Reduction)
**Context:** Prevents nurses from arriving at homes where no supplies exist.
- **US-1.1:** As a **Client**, I must see a checklist of required items (e.g., "Syringe", "Medication") specific to my selected service before I can pay.
- **US-1.2:** As a **Professional**, I want the booking to be tagged as "Materials Verified" so I know I don't need to bring the consumables.

## Epic 2: Family Management (UX)
**Context:** Elderly care is often managed by children.
- **US-2.1:** As a **Daughter (User)**, I want to create a profile for my **Father**, so his medical history is kept separate from mine.
- **US-2.2:** As a **Professional**, I want to see the *Patient's* name and age on the job card, not the *Payer's* name.

## Epic 3: The "Smart Corridor" (Pricing)
**Context:** Prevents price wars and gouging.
- **US-3.1:** As an **Admin**, I want to set a Min/Max price for "Wound Care" (e.g., €15-€30).
- **US-3.2:** As a **Professional**, I want to set my own price, but the system should block me if I try to go above the maximum allowed.

## Epic 4: Safety & Trust
- **US-4.1:** As a **Professional**, I need an **SOS Button** on my active screen that logs my GPS location and alerts the Admin immediately.
- **US-4.2:** As a **Client**, I want to see a "Verified" badge on the nurse's profile that confirms their license (Cédula) has been manually checked.
